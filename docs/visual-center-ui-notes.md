# AutoTariff Studio 界面实现记录

2026-11-03。界面按 `docs/visual-center-product.md` 与 `src/web/types.ts` 实现。本文记录界面行为，不替代产品验收结论。

页面使用本地静态 HTML、CSS 与 JavaScript，无新增依赖。界面入口为 `http://127.0.0.1:3000/`，由同源 Node 服务提供。

## 视觉与结构

使用雾蓝 `#F4F7FB`、白色 `#FFFFFF`、深海蓝 `#162B43`、动作蓝 `#235FE8`、待复核琥珀 `#A56513` 与失败红 `#B13F48`。正文优先采用本地 Avenir Next、Avenir 与 PingFang SC。代码和原文坐标使用系统等宽字体，不加载网络字体。

桌面以 220 px 会话栏、较宽对话区和证据区组成工作台。证据时间线是主要视觉线索。1200 px 以下会话栏折叠为抽屉，768 px 以下切换对话、执行过程和结果证据。表格在独立区域横向滚动，输入区保持在对话区底部。

Experience First 原则使页面围绕选择文件、发送要求和核对证据组织。Model the Domain 原则使会话、运行、轮次、待确认请求和草稿分别保存。frontend-design 指导使真实工具时间线成为视觉重点，页面没有宣传首屏或通用指标卡。

UI/UX Pro Max 的两次设计查询都未返回适合本产品的页面模式。实现采用产品文件的既定视觉要求，并采用该技能中关于焦点、响应式、文本对比和减少动态效果的通用指导。

## 已接入行为

- 读取试点文件、已有会话、历史运行、任务预算和工程测试报告。
- 创建文件对应的会话。上传一个原文件与 UTF-8 的 TXT 或 Markdown 说明，显示后端拒绝原因。
- 保存真实用户消息和 Agent 回复。仅发送消息会调用执行接口。
- 同一会话执行中禁用发送，保留后续草稿。网络发送未确认时，只有用户明确重试才重新提交相同请求编号。
- 活跃运行轮询只使用读取请求。刷新、切换证据和重新连接均不自动提交消息。
- 查看真实工具开始与结束、运行状态、修复轮次、分页结果、预期与实际差异、原文坐标和登记产物。
- 查看与下载登记产物。工程测试报告单独展示来源、生成时间与原文，不替代业务检查结论。
- 历史运行只读。选择旧运行或旧轮次时，输入区提示追问基于本会话最新运行结果。
- 处理空会话、读取中、运行中、断线、预算不足、未配置模型、阻断、待复核和产物缺失状态。

文本通过 DOM `textContent` 写入。后端文本不进入 `innerHTML`。原文、模型输出和报告内容均按文本显示。

界面支持明确的键盘焦点、对话框、移动端侧栏焦点约束、Enter 发送、Shift + Enter 换行、Cmd/Ctrl + K 新建以及 `prefers-reduced-motion`。轮询保留输入焦点、草稿、证据滚动位置与被聚焦的控件。

## 结果页的当前页面提示

结果表在 `#` 后独立展示「当前页面提示」列，只读取当前页每行的 `运价有效开始时间` 和 `运价有效结束时间`。两者必须均为严格 `YYYY-MM-DD` 字符串、年份 `0001`–`9999` 的真实公历日期，校验月份、天数和闰年；结束日严格早于开始日才提示。正常、同日、缺失、空值、数字、日期时间、其他格式及非法日期均不提示，不使用 `ETD` 或当前日期推断，也不自动修正日期。

倒置行常显「运价有效期倒置」、带“开始日”“结束日”标签的原始日期和「请回查原文」，保留原行号、业务字段、坐标与顺序；其他行提示单元格留空，不表示业务通过。提示可换行，并随表格在自身区域横向滚动，桌面与窄屏均不依赖悬停阅读。

表格前说明「当前页面提示仅基于已保存结果，不计入原检查报告，也不改变业务状态。」此观察不写入 `issues`、不增加原报告问题数、不改变待复核等状态，也不回填历史产物。仅计算已加载页，不代表整轮统计。翻页、切轮与重新渲染均按当前记录计算；零记录、尚未产生和读取失败维持原空态与报告可用性显示。
