# 在浏览器中推动运价 Agent

本地工作台已接入现有 Pi Agent Loop。产品经理按冻结的12项标准完成验收。用户在同一个页面发要求、查看工具动作和脚本轮次、核对结果，并继续追问。

## 打开并完成一次工作

浏览器打开 http://127.0.0.1:3000。服务停止后，在项目目录运行下面的命令。

```bash
scripts/run_with_temp_runtime.sh npm run web
```

1. 点击“新建会话”。
2. 选择“受控试点 · Excel”，或上传原文件和配套说明。
3. 输入“抽取全部运价，执行后处理和独立检查，有差异时修复脚本并重跑”。
4. 在右侧查看执行过程、轮次、结果、产物和工程测试。
5. 继续输入“解释某条记录的价格和检查结论”。追问使用本会话最新结果，查看旧轮次不会改变追问依据。

“历史运行”提供已有真实修复证据。打开和下载历史不会调用模型。真实修复记录的第一轮缺少 Rates!R4C1，第二轮补齐。页面将历史证据与当前执行明确区分。
