# 最终设计与实现边界

2026-11-03。候选 A 是基础；合并候选 B 的阶段/终态分离、重放策略、条款追踪和恢复语义。此前以 B 为基础、业务状态只在内存和 JSON 清单内的原型描述已废止。候选文档是历史提案，最终行为以本文件、源码和验收矩阵为准。

```text
原件与本单证要求 → 本项目不可变输入副本与工作解释
→ 全量源目录 + 分页证据 + 区域/上下文
→ Pi 提议：选路、生成、查询参考、复制修改、执行、检查
→ 宿主 SQLite 先登记动作与预算 → OS 隔离脚本 / 直接模型 JSON
→ 原始结果 → 完整字段契约后处理 → 独立重读原文检查
→ 带坐标反馈 → 新轮次 / 路径切换 → 有限预算内复核归档
```

Pi Durable 使用 TypeScript SDK，负责会话与工具调用。没有给 Agent 通用 shell 或任意文件权限。业务账本与 Pi 会话存储分离，业务权威事实是 `template_runs/closure.sqlite`。生成 Python 独立运行于 macOS Seatbelt；不在宿主进程执行生成代码。

`manifest.phase` 是已提交的恢复位置，`decision` 是终态；兼容字段 `status` 是导出显示值。正在执行的动作由 SQLite `STARTED` 表达，动作完成后才提交下一个阶段。尝试保留完整脚本/直接响应、原始结果、后处理结果、报告、反馈引用和差异，不追加上一轮记录。

所有产物绑定摘要。文件先以不可变方式落盘，动作结果及运行状态再提交 SQLite。清单是可读快照，不能替代 SQLite。单运行只能有一个活跃写者。重复已完成动作验证原产物后返回原结果。

模型和脚本执行前预留预算。模型 SDK 内部重试关闭，每个实际调用独立登记。模型响应在完整回执后结算；未知回执保留预留并阻断。已完成模型响应支持按请求身份复用。预算预检拒绝不会伪造收费不确定性。一次安全动作最多重试一次；两次无进展停止。恢复保留原日期、年份、解释、要求、基准脚本和预算。

检查器重新打开输入，独立计算预期记录与覆盖，不读取候选脚本生成答案，也不相信候选自报行数。生产后处理与独立后处理参考实现分开，字面日期/价格示例另有固定测试。负价保留；合法重复保留；合法归一化不会被一律当作错误。

非 Excel 输入先保留原文页/段落/图像识别证据。转换是独立动作，有来源映射和覆盖检查。后续脚本结果始终与原件重读结果比较，转换丢行不能由候选自行补造来源。模型可选择直接抽取，修复必须产生新轮次。

模板注册仅为试点候选，保存逐字段要求全文、条款标识、检查标识、实现位置、脚本及实际校验报告。注册时核对同一已验证运行的绑定，不能把任意脚本和报告拼接。要求更新创建新版本；新运行读取当前版本，已有运行保留原绑定。不发布正式模板。

本系统证明工程闭环。工作解释不授予业务 PASS；受控工程用例 PASS 与业务 REVIEW 分开。源数据缺失、日期未知、布局歧义、缺依赖或检查器失败均不能变成成功。
